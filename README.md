# Alborz Seifaei — Portfolio

Static personal portfolio for Alborz Seifaei, focused on AI automation, AI agents, computer vision, and intelligent products.

**Live site:** https://alborz-seifaei-portfolio-sand.vercel.app/

## Repository structure

The deployable static website is contained in `dist/`:

- `dist/index.html`
- `dist/styles.css`
- `dist/script.js`
- image and favicon assets

`vercel.json` configures Vercel to publish that directory. This repository currently contains the deployable static source rather than a separate framework project or build pipeline.

## Deploy on Vercel

1. Import `Alborzsfe/alborz-seifaei-portfolio` in Vercel.
2. Keep the repository configuration.
3. Deploy.

## Local preview

```bash
python -m http.server 8000 --directory dist
```

Open `http://localhost:8000`.
