# Alborz Seifaei — Portfolio

Personal portfolio for Alborz Seifaei, focused on AI automation, AI agents, computer vision, and intelligent products.

## Deploy on Vercel

1. Open https://vercel.com/new
2. Import `Alborzsfe/alborz-seifaei-portfolio`
3. Keep the default settings and select **Deploy**

The repository includes `vercel.json`; Vercel publishes the `dist` directory automatically.
